# 🥋 Judo Flashcards

A simple, mobile-friendly flashcard site for learning Judo terminology.

## 🌐 Live Site
https://tkimnguyen.github.io/judo-flashcards/

## ✨ Features
- Tap card to flip
- Next / Previous navigation
- Shuffle deck
- Mobile-friendly design

## 🚀 Usage
1. Open the site
2. Tap card to reveal answer
3. Use buttons to navigate or shuffle

## 📦 Tech
- HTML
- CSS
- JavaScript (vanilla)

## 🧠 Data
Includes:
- Judo commands
- Techniques
- Terminology
- History
- Ranking system

Built for dojo training and student study.
